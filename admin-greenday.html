Terapkan ke Aplikasi

  1. Unduh berkas dengan tombol di bawah — hasilnya bernama pengumuman.json.
  2. Unggah / timpa file pengumuman.json di folder aplikasi pada hostingmu (GitHub: tombol "Add file → Upload files" lalu commit; Netlify: seret ulang folder GreenDay-mu).
  3. Selesai — pengumuman otomatis muncul di halaman Beranda aplikasi untuk semua pengguna saat mereka online.

Daftar di halaman ini tersimpan otomatis di browser ini (LocalStorage) — kamu bisa menutup halaman dan melanjutkan kapan saja. Tombol "Impor" dipakai untuk memindahkan daftar ke browser/laptop lain lewat file pengumuman.json.
